# Antonio Grill — Demonstração mobile

Landing page mobile-first criada para apresentação comercial da Antonio Grill Churrascaria.

- Barra superior fixa com logo
- Banner compacto
- Destaques do dia
- Categorias pequenas em rolagem horizontal
- Seções em ordem: Executivos, Acompanhamentos e Linguiças
- Cards mais altos e estreitos
- Fotos recortadas das imagens fornecidas pelo cliente
- Botões demonstrativos de pedido/carrinho
- Atalho para WhatsApp
- Navbar inferior fixa

Projeto estático pronto para Vercel.
